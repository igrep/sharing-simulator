Change the design of embedded.html and add a new feature to it:

1. Tabbed interface:
    - Switch between the Graph tab and Errors tab using tabs instead of displaying them side by side.
    - If the input code has some errors, the Errors tab should be highlighted to indicate that there are errors to view.
    - Add a query parameter to set the default tab to be displayed when the page loads. `index.html` doesn't need to provide a way to set this parameter, but it should be possible to set it manually in the URL.
2. Console Tab:
    - Add new tab to display output from `console.log` calls in the evaluated code.
        - Support only `console.log`. Throw `UnsupportedSyntaxError` for other console methods.
    - Displays logs from both threads side by side.
    - Clear every time the user changes the input code in index.html.
    - If the user selects the "Run real worker code" mode, the console tab should be displayed by default.
